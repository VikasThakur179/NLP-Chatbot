# NLP-Chatbot

## 📌 Overview

A Python-based rule-driven chatbot developed using Natural Language Processing techniques. The chatbot processes user input and generates appropriate responses based on predefined conversational patterns.

## 🎯 Objective

The objective of this project is to demonstrate the use of NLP techniques for building a simple conversational system that can understand basic user queries and respond accordingly.

## 🛠️ Technologies Used

- Python
- NLTK
- Regular Expressions
- Jupyter Notebook

## ⚙️ Key Features

- User input processing
- Text tokenization
- Stemming and lemmatization
- Pattern-based response generation
- Interactive conversation
- Basic NLP text processing
